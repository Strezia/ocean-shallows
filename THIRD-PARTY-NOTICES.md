## Fonts

This project loads **no web fonts**. The interface uses system fonts
(`system-ui` for body text, `Georgia` for headings), so no font license applies.

The original version referenced Google Fonts (Fraunces and Nunito Sans, both
SIL Open Font License). Those links were removed so the page never blocks on a
third-party font server.
